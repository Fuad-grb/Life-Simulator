# Life-Simulator
Life simulator with deep genetic, neurobiological and psychological systems

## Description

An expanded version of the Sims concept with a focus on realistic modeling:
- Genetics - characters inherit not only appearance, but also inclinations, talents, predispositions to diseases
- Neuroscience - modeling of neurotransmitters affects the behavior and decisions of the character
- Psychology - a developed system of emotions, traumas, cognitive distortions and defense mechanisms
- Social dynamics - complex relationships between characters
- AI agents - characters make autonomous decisions

## Installation

Clone the repository
git clone https://github.com/Fuad-grb/Life-Simulator.git
cd life-simulator
Create a virtual environment
# Create virtual environment
python -m venv venv

# Activate on Windows
.\venv\Scripts\activate

# Activate on Linux/Mac
venv/bin/activate
Install dependencies
pip install -r requirements.txt
## Usage
python -m src.main
